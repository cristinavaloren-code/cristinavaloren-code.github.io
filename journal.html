Entry 001 — Starting this site

I've been using AI tools for about a year now — mostly Claude, some NotebookLM — and I kept thinking someone should document what it actually looks like to learn this as a teacher, not a developer. So I'm doing it myself.

This site is the first step. I built it with help from Claude, pushed it to GitHub, and figured out GitHub Pages. It took longer than I expected and less time than I feared.

What I want this journal to be: honest notes about the process. What I tried, what confused me, what clicked. No performance, no pretending I knew what I was doing.

More entries coming. This is entry one.
